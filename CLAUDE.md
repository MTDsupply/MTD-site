# Made to Disappear site

- Brand card and site map: docs/brand-card.md (routes, data model, claims rules). Colour follows the brand card palette by the user's choice (the brand kit's ink-only scheme was rejected as too monochrome): Soil #2B2B2B for type and the footer, Sage #4F6F52 for primary buttons, bands, the trail, ridgelines and the 2 px rule under the header, Clay for in-stock and coming-soon tags plus the single hero sun, Fog for coming-soon tiles and dividers, Paper ground, white cards. The kit still governs Outfit 700/800 headlines with the kit type scale (.t-hero/.t-section/.t-page/.t-heading/.t-card); Inter 15/24 body; JetBrains Mono for SKUs (.sku); square tiles, 4 px corners on controls; the supplied wordmark ("made to disappear." with the full stop, no dissolve) used intact; the round "home compostable" badge is the only secondary mark, used beside certification claims.
- Do not mention shipping speed (no same-day, cutoffs or dispatch times) and never present the round wordmark badge as a certification mark: it is our logo, not TÜV Austria's.
- The site never shows its own to-do list: no "pending", "TODO" or placeholder values in copy, chips, tables or the PDF. Missing data (certificate numbers, phone) is omitted, not labelled. Ask the user for it in chat instead.
- Never use the words biodegradable, marine, ocean, landfill, municipal, green bin, eco or planet-friendly in site copy. `npm run lint:copy` enforces this and runs before every build.
- The claim is about the material, never the finished product: "100% certified home-compostable material", certified by TÜV Austria, per SKU. The range is cups and lids only (straws were removed from the site on 2026-10-30; the straw photos stay in docs/source-photos/straws).
- Catalogue source of truth is src/lib/catalog/seed.ts; `npm run db:seed` pushes it to Supabase. Category `status` drives every surface.
- Next.js 16 with Cache Components: read node_modules/next/dist/docs before using unfamiliar APIs. Cookie/header reads must sit inside Suspense.
- Home page follows the Better Packaging structure the user asked for (October 2026): full-bleed hero video with quick-shop buttons, category tiles with taglines, certification trust strip, alternating feature blocks, business band, product grid, founder quote, proof, newsletter. The hero prefers public/hero.mp4 + hero-poster.jpg when present.
- Paid-traffic landing pages live under /go/ (none live at the moment; the scaffold is ChromeGate + LandingChrome): no site header or footer (ChromeGate), noindex, Meta Pixel events (ViewContent, AddToCart, InitiateCheckout, Purchase) fire when NEXT_PUBLIC_META_PIXEL_ID is set. Keep claims substantiated: no invented reviews or urgency.
- Shipping rates live in src/lib/shipping.ts (proposed benchmarks, Oct 2026; user to confirm). Cart has a Canada/US ship-to selector; checkout restricts the address country to it and adds one fixed shipping option. Stripe Tax is attempted and silently skipped until registrations exist in the Stripe dashboard. Webhook sends the customer receipt (Resend) and a Meta Conversions API Purchase (META_CAPI_TOKEN) deduplicated with the pixel by session id.
- Legal pages live at /privacy, /terms and /shipping-returns with conservative default policies the user should review; contact email defaults to hello@madetodisappear.com. The floating-dot background (AmbientDissolve) was removed as visual noise; keep the mesh and grain only. Product image frames are 4:3.
- Atmosphere: generated landscape imagery in public/atmosphere (misty peaks hero with a looping clip, fog forest for dark bands, moss for proof, meadow for about), rendered through src/components/scene/Atmosphere.tsx and HeroMedia.tsx with slow drift, scroll parallax and Paper fades; reveals via src/components/Reveal.tsx; all on the `motion` library with reduced-motion fallbacks. No wayfinding metaphors (no trail markers, elevation readouts or summit labels): the mountain feeling comes from the imagery, not signposts. Dots everywhere come from the dissolve system (Dissolve, AmbientDissolve). Verify scroll effects with the DevTools harness pattern (CDP scroll + screenshot), not plain headless screenshots.
- Press: src/components/PressBand.tsx renders the "As heard on" strip on the home page (CBC Radio One, All Points West with Jason D'Souza). The CBC gem (public/press/cbc.svg, public-domain shape from Wikimedia Commons) is used for identification only: CBC red, fixed size, never recoloured or implied as an endorsement. Add the segment link to PRESS[].href when the user supplies it.
